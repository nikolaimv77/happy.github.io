# Обновление дизайна — reference style v2

- Композиция первого экрана приведена ближе к предоставленному референсу: заголовок, сердце, подпись, четыре карточки таймера, декоративный разделитель, романтическое сообщение.
- Карточки таймера используют полупрозрачный glassmorphism с размытием фона, золотым контуром и мягким свечением.
- Добавлены декоративные золотые акценты, сиреневые цветочные детали и адаптивная компоновка для Telegram Mini App.
- Логика PHP-бота, главы сюрприза и таймер сохранены.

Для публикации скопируйте содержимое `public/` в репозиторий GitHub Pages и отправьте commit.
