## Что обновлено
- Mini App: глубокий фиолетовый `#390038`, сливовый `#7A3776`, сиреневый `#AF7BBD`, лавандовый `#CAB3E6`, светлая лаванда `#DBD9E8` и мерцающее золото.

- В Telegram кнопка Web App открывает первую главу напрямую (`?story=1`).
- Временно разрешён просмотр всех глав через `PREVIEW_MODE=1`.
- Обратный отсчёт до 30 октября сохранён.

## Установка
1. Сделай резервную копию текущего проекта.
2. Скопируй файлы из архива в проект, не удаляя свой локальный `.env`. В архиве нет токена и секретов.
3. Для PHP-бота: `composer install`, затем проверь `.env` и выставь `PREVIEW_MODE=1`.
4. Перезапусти единственный запущенный экземпляр бота: останови старый процесс `Ctrl+C`, затем `php bin/bot.php`. Не запускай два long-polling процесса одновременно.
5. Для сайта закоммить `public/index.html`, `public/assets/` и `.github/workflows/jekyll-gh-pages.yml`, затем `git push origin main`; дождись успешного GitHub Actions.
6. После утверждения глав установи `PREVIEW_MODE=0` в `.env`, чтобы вернуть ограничение доступа в нативных командах бота. В `public/assets/js/app.js` также установи `PREVIEW_MODE = false`, если хочешь вернуть дату-блокировку на сайте. Затем снова опубликуй сайт.

## Важно
GitHub Pages публикует только Mini App (статические HTML/CSS/JS); PHP-бот должен постоянно работать отдельно на Mac или сервере. `.env` не добавляй в Git.
