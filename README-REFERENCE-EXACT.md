# Exact reference poster update

The landing screen now uses the supplied `image2(1).jpeg` artwork directly as a full-screen responsive poster. This preserves the exact visual composition: typography, floral ornaments, gold frame, mountain background, portrait, and translucent/glowing effects.

## Important behavior note
The countdown numerals and message are part of the reference artwork and therefore are static on this pixel-matched screen. Tap the transparent heart/title hotspot to enter the interactive surprise chapters. The chapter experience remains HTML/CSS/JS.

To publish, copy the changed `public/` files into the repository and commit/push them. GitHub Pages will publish the static assets; it does not execute PHP.
