# Happy Day My Love — исправления интерфейса

## Что изменено
- Главный экран больше не использует открытку с уже напечатанным таймером как фон: для фона используется чистый `birthday-portrait.jpg`, а заголовок, текст, таймер и кнопка — отдельные HTML-элементы. Это устраняет дублирование цифр.
- Добавлен каллиграфический шрифт Great Vibes для «Моё солнышко» и Cormorant Garamond для подписи и карточек таймера.
- Счётчик обновляется каждую секунду и считает до 30 октября 2026 года по времени Ташкента.
- Оставлена одна музыкальная дорожка с кнопкой включения/выключения; отдельного переключателя песен нет.
- `.env` исключён из Git через `.gitignore`; используйте `.env.example` как шаблон.
- Версии CSS/JS обновлены для сброса браузерного кэша.

## Проверка
- `node --check public/assets/js/app.js`
- `php -l` для PHP-файлов

## Публикация GitHub Pages
Из корня репозитория:
```bash
git add .gitignore public README-UPDATE.md
git commit -m "Fix countdown layout and polish birthday mini app"
git push origin main
```
После публикации откройте Mini App заново. Если Telegram показывает старую версию, закройте Mini App полностью и откройте повторно.
