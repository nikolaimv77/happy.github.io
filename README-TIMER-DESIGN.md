# Happy Day My Love — Deep Lilac Timer Design

Обновлён главный экран Mini App: фотография стала крупным верхним блоком, ниже расположены обращение, текст, живой обратный отсчёт до 30 октября 2026 года и кнопка «Открыть сюрприз». Оформление использует глубокую сиренево-фиолетовую палитру, золотую рамку, свечение и анимированные частицы.

## Проверка
1. Открой `public/index.html` в браузере или опубликуй `public/` на GitHub Pages.
2. Таймер обновляется каждую секунду. Целевая дата: `2026-10-30T00:00:00+05:00` в `public/assets/js/app.js`.
3. Режим просмотра глав временно включён (`PREVIEW_MODE = true` в JS).
4. Telegram-бот запускается отдельно командой `php bin/bot.php`; GitHub Pages исполняет только статические HTML/CSS/JS и не запускает PHP.
5. Существующий `.env` не заменяйте и токен бота никому не отправляйте.
