# Happy Day My Love — обновлённый дизайн

Главная страница мини-приложения оформлена по предоставленному референсу: фотография на весь экран, декоративная золотая рамка, глубокая сиреневая палитра, романтический заголовок, динамический таймер и кнопка «Открыть сюрприз».

## Файлы
- `public/index.html` — структура страницы.
- `public/assets/css/style.css` — адаптивный дизайн и анимации.
- `public/assets/js/app.js` — обратный отсчёт и главы-поздравления.
- `public/assets/images/birthday-portrait.jpg` — фон-портрет для первого экрана.

## Публикация на GitHub Pages
Скопируйте изменения в свой рабочий репозиторий, затем выполните:

```bash
git add public
git commit -m "Match birthday mini app to reference design"
git push origin main
```

После успешного завершения workflow GitHub Actions обновите страницу с очисткой кэша.

## Предпросмотр глав
Для просмотра глав до даты рождения откройте страницу с параметрами `?preview=1&story=1`.
